# 산책할개

> 지역별 실시간 날씨를 확인하고 반려견과 산책하기 좋은 시간을 추천받는 견주용 날씨 서비스

산책할개는 기온, 비 올 확률, 습도, 풍속, 미세먼지와 반려견 정보를 함께 확인해 산책하기 좋은 날씨인지 알려주는 서비스입니다. 날씨 숫자만 나열하기보다 견주가 바로 이해할 수 있도록 **멍산책 지수**와 산책 준비사항으로 표현했습니다.

## 배포 주소

[산책할개 바로가기](https://skala-3o9is70un-jeam2.vercel.app/)

## 주요 기능

- 전국 17개 주요 지역의 실시간 날씨 조회
- 지역명과 한글 초성을 이용한 검색
- 하트 버튼을 이용한 지역 즐겨찾기와 우선 정렬
- 반려견 이름, 크기, 나이대 설정
- 날씨와 반려견 정보를 반영한 멍산책 지수 제공
- 체감온도, 습도, 풍속, 미세먼지를 포함한 상세 날씨
- 가로 스크롤 방식의 1시간 단위 예보와 5일 예보
- 섭씨·화씨 단위 변경과 낮·밤 화면 모드
- 랜덤 강아지 사진과 한국어 강아지 상식
- 수업에서 작성한 실습 과제와 코드 챌린지 보관

## 사용 API

| API                         | 사용 목적                        | API 키 |
| --------------------------- | -------------------------------- | ------ |
| OpenWeather Current Weather | 현재 날씨와 체감온도 조회        | 필요   |
| OpenWeather 5 Day Forecast  | 강수 확률과 단기 예보 조회       | 필요   |
| OpenWeather Air Pollution   | PM10과 대기질 조회               | 필요   |
| Open-Meteo                  | 1시간 단위 예보와 5일 예보 조회  | 불필요 |
| Dog CEO                     | 랜덤 강아지 사진 조회            | 불필요 |
| Dog API                     | 랜덤 강아지 상식 조회            | 불필요 |
| MyMemory                    | 영어 강아지 상식을 한국어로 번역 | 불필요 |

OpenWeather에서 발급받은 키 하나를 현재 날씨, 예보, 대기질 API에 공통으로 사용했습니다. 나머지 API는 별도의 키 없이 호출할 수 있는 공개 API입니다.

## 멍산책 지수 계산 방법

멍산책 지수는 100점에서 시작해 산책하기 불편한 날씨 조건에 따라 점수를 차감하고, 최저 점수는 0점으로 제한했습니다.

| 조건                         |  감점 |
| ---------------------------- | ----: |
| 체감온도 30℃ 이상            | -35점 |
| 체감온도 26℃ 이상 30℃ 미만   | -15점 |
| 체감온도 0℃ 이하             | -30점 |
| 체감온도 0℃ 초과 8℃ 이하     | -15점 |
| 습도 80% 이상                | -10점 |
| 풍속 8m/s 이상               | -15점 |
| 비 올 확률 60% 이상          | -25점 |
| 비 올 확률 30% 이상 60% 미만 | -10점 |
| 대기질 3단계                 | -15점 |
| 대기질 4단계 이상            | -30점 |
| 어린 강아지                  |  -5점 |
| 노령견                       | -10점 |

현재 날씨에 체감온도가 없으면 실제 기온을 대신 사용합니다. 메인 지역 카드는 바로 확인할 수 있는 날씨 정보를 기준으로 계산하고, 상세 화면에서는 체감온도와 대기질까지 반영합니다. 반려견 크기는 점수에서 차감하지 않고 산책 준비사항을 추천할 때 사용합니다.

## 트러블슈팅

### 1. 서비스 소개 주소가 변경되지 않던 문제

처음에는 메뉴 글자만 만들고 `RouterLink`와 `/about` 라우트를 제대로 연결하지 않아 서비스 소개를 눌러도 주소가 변경되지 않았습니다. `App.vue`에 `RouterLink`를 배치하고 라우터에 소개 페이지를 등록해 해결했습니다. 상세 페이지는 `/weather/:cityId`처럼 동적 경로로 구성했습니다.

### 2. API 키를 넣었지만 날씨를 불러오지 못한 문제

OpenWeather 키를 발급받은 직후에는 키가 활성화되지 않아 요청이 실패했습니다. 키 상태가 `Active`인지 확인하고 잠시 기다린 뒤 다시 요청했습니다. 키는 코드에 직접 작성하지 않고 `.env`의 `VITE_OPENWEATHER_API_KEY`로 관리했으며, Vercel에도 같은 이름의 환경변수를 등록했습니다.

### 3. 1시간 단위 예보가 필요했던 문제

OpenWeather의 5일 예보 데이터는 3시간 간격이라 원하는 시간별 화면을 만들기 어려웠습니다. 현재 날씨와 대기질은 OpenWeather를 사용하고, 1시간 단위와 5일 예보는 Open-Meteo를 추가로 사용했습니다. 두 API의 응답 형태가 달라 상세 화면에서 필요한 형태로 다시 가공했습니다.

### 4. 지역별 요청 중 하나가 실패하면 전체 화면이 멈추던 문제

여러 지역의 날씨를 한 번에 요청할 때 한 지역의 요청만 실패해도 전체 결과를 사용하지 못하는 문제가 있었습니다. `Promise.allSettled()`를 사용해 성공한 지역은 그대로 표시하고, 실패한 지역의 개수만 안내하도록 변경했습니다.

### 5. 메인과 상세 화면의 산책지수 계산이 중복된 문제

처음에는 `WeatherCard`와 `WalkRecommendationCard`에서 산책지수를 각각 계산했습니다. 조건을 수정할 때 두 파일을 모두 바꿔야 하고 점수가 달라질 수 있어 계산 로직을 `utils/walkScore.js`로 분리했습니다.

### 6. 밤 모드에서 글자가 보이지 않던 문제

밝은 카드 안의 글자까지 흰색으로 변경되어 비 올 확률과 멍산책 지수, 학습자료실 내용이 보이지 않았습니다. 밝은 영역은 어두운 글자를 유지하고, 학습자료실은 밤 모드에서 배경과 글자 색을 함께 변경하도록 CSS 선택자를 나누어 해결했습니다.

## 실행 방법

```bash
git clone https://github.com/SKALA4-jaem/skala-vue.git
cd skala-vue
npm install
```

프로젝트 최상위 경로에 `.env` 파일을 만들고 OpenWeather API 키를 입력합니다.

```env
VITE_OPENWEATHER_API_KEY=발급받은_API_KEY
```

개발 서버를 실행합니다.

```bash
npm run dev
```

기본 주소는 `http://localhost:3000`입니다.

## 배포 전 확인

```bash
npm run lint
npm run build:production
```

`.env` 파일은 `.gitignore`에 등록되어 GitHub에 올라가지 않습니다. Vercel로 배포할 때는 프로젝트 설정에서 `VITE_OPENWEATHER_API_KEY`를 별도로 등록해야 합니다.

> 멍산책 지수는 학습 프로젝트에서 제공하는 참고 정보입니다. 실제 산책 여부는 반려견의 건강 상태와 기상 특보를 함께 확인해 판단해야 합니다.
